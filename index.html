Initialize as Frame Project

This project isn't set up with Frame yet. Initialize it to enable AI context, task tracking, and session notes.

This will create the following files in your project:

  • 📁 .frame/ everything Frame writes lives here
  • 📄 .frame/AGENTS.md AI instructions
  • 📄 .frame/STRUCTURE.json module map
  • 📄 .frame/PROJECT_NOTES.md session notes
  • 📄 .frame/tasks.json task tracking
  • 📄 .frame/QUICKSTART.md getting started
  • 📁 .frame/bin/ Frame's parser and helper scripts
  • 🔗 .claude/rules/frame.md a copy of .frame/AGENTS.md, kept in sync, for Claude Code to read

Nothing is added to your project root, and no existing file is read, moved or replaced — your CLAUDE.md and AGENTS.md stay yours.

How should Frame's files relate to git?

Needs Claude Code new enough to load .claude/rules/ — verified with Claude Code 2.1.x. Run /context in a session to confirm .claude/rules/frame.md loaded.
